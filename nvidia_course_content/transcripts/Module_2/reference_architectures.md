The DGX B200 system includes 8 NVIDIA Blackwell ​GPUs and can deliver 72 petaflops FP8 performance, making it well-suited to handle ​any enterprise AI workload. The DGX H200 and H100 systems each feature 8 NVIDIA Hopper GPUs ​and can deliver 32 petaflops FP8 performance, making them excellent choices for AI development. ​DGX systems have 1 gigabit Ethernet port for out-of-band management through the BaseBoard ​Management Controller. The BaseBoard Management Controller allows for out-of-band remote ​management of the device even when the system is powered off. ​The NVIDIA DGX BasePod reference architecture incorporates the ConnectX 7 network adapters ​for the DGX H200 and H100 systems, while the DGX B200 systems include both ConnectX 7 and ​BlueField 3 network adapters. The network adapters can be configured for InfiniBand ​or Ethernet connections. Typically, InfiniBand connections are used for the compute network ​and Ethernet is used for the storage, in-band management, and out-of-band management networks. 
​The DGX BasePod reference architecture also includes an overview of the NVIDIA switches ​that can be employed in DGX BasePod configurations. This includes the QM9700 and QM8700 InfiniBand ​switches. NDR stands for Next Data Rate, which is 400 Gbps. The QM9700 InfiniBand switch is ​used 400 Gbps or 200 Gbps data communication with the DGX H100 system or DGX A100 system ​respectively depending on the BasePod configuration. HDR stands for High Data Rate, ​which is 200 Gbps. This QM8700 switch can be used with the DGX A100 system in BasePod ​configurations. The SN5600 Ethernet switch is used for GPU-to-GPU fabrics and offers speeds ​between 10 Gbps Ethernet and 800 Gbps Ethernet. The SN4600 is used for in-band management and ​can also be used for storage fabrics. It offers speeds between 1 Gbps Ethernet and 200 Gbps ​Ethernet. The SN2201 Ethernet switch is used for out-of-band management connections in the ​BasePod configuration with speeds between 1 Gbps Ethernet and 100 Gbps Ethernet.

​The DGX SuperPod architecture is a combination of DGX systems, InfiniBand and Ethernet networking, ​management nodes, storage, and all the necessary software optimized to streamline ​AI development and deployment.
