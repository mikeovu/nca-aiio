​Now suppose you wish to exclude certain elements from your image, like clouds. ​You can do this using negative prompts. ​Click on View Parameters to access the box for negative prompts. ​Negative prompts are words that describe what we don't want the AI model to generate. ​For example, let's suppose I didn't want to see clouds in my images. ​Then I would enter cloud in the negative prompt box. ​Let's go ahead and do that. 
​I'll erase the sample prompt here and type cloud. ​Let's run the model again. ​As we can see, most of our images don't contain clouds. ​Let's explore the other parameters available. ​The seed parameter is a positive whole number starting from zero that determines the starting ​point for the image generation process. ​It influences the output image from a given text prompt. ​When you provide a text prompt to an AI image generation model, the model processes the ​prompt and generates a corresponding image. 
​Because the generation process involves randomness, running the same prompt multiple times can ​produce different images. ​This is where seeds come into play. ​Using the same seed value ensures you get the exact same image from a given text prompt. ​This is useful when you want to generate variations of an image while keeping certain aspects ​consistent. ​Also, different seed values will result in different random initializations, leading ​to different images being generated from the same prompt. ​Let's see an example. ​Until now, we've been using a seed value of zero. 
​So if I click Run again, we can see that the images are very similar to the previous ones. ​Now let's change the seed value to 42 and click on Run. ​As we can see, the images generated are different from those generated with a seed value of ​zero. ​Let's change the seed value back to zero and click on Run again. ​This produces images very similar to ones we got before with the same seed value. ​As we can see, the seed parameter allows us to explore a range of possibilities while ​maintaining some control over the randomness. ​The media type parameter lets you choose between photography and illustration. 
​This parameter tells the model whether it should output photographic images or illustrations. ​Let's change this parameter to illustration and click Run to see how our images change. ​As we can see, our images now look like illustrations rather than photographs. ​Now let's change this back to photography. ​Adjusting the aspect ratio parameter changes the image dimensions. ​Right now we're using an aspect ratio of 1 to 1. ​Let's change that to 16 by 9 and click Run to see the result. 
​As we can see, the images are more rectangular than before. ​Now let's look at the prompt weight. ​The prompt weight controls how closely the model follows the prompt. ​Lower values encourage more creativity, while higher numbers will tell the model to follow ​the prompt exactly. ​A value of 7.5 gives a good balance between creativity and following the user's prompt. ​Let's try a value of 1 and click Run again to see how our images change. ​For example, the top right image doesn't have a wooden cabin. 
​The water in the lower left image looks more like a lake than a river and two of the images ​have clouds. ​As we can see, our images don't follow the prompts as well as before. ​Now let's quickly look at another feature of this model. ​Go back to the Feature box and select In Painting. ​This feature allows you to modify an existing image using a mask and text prompt. ​In the Input Image box, click on Select Image. ​Here we're given some images to choose from.

​Now that you know the basics of how to generate and modify images, you can experiment yourself ​and try out different AI models and play around with different prompts. ​Here are some tips for getting good results. ​Be as specific as possible in your prompts. ​Use descriptive adjectives to add details to your prompts. ​Combine multiple elements for complex scenes. ​Utilize negative prompts to exclude unwanted elements. ​Experiment with different styles and perspectives. 
​Consider the lighting, colors, and composition of your desired image. ​Reference existing images or artwork for guidance. ​Break down complex scenes into smaller, more manageable prompts. ​Iterate and refine your prompts based on the generated images. ​Now you're ready to enjoy generative AI image applications. ​Have fun and be creative!
