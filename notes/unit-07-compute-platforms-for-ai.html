Lesson 1 of 4Data Center Platform

What Unit 7 as a whole should teach you

  1. The key components and features of the NVIDIA data center platform.
  2. GPU and CPU requirements for AI data centers, the products, and their use cases.
  3. The purpose and capabilities of multi-GPU systems.
  4. Multi-node GPU interconnect technology.
  5. The role of DPUs and DOCA.
  6. The benefits of NVIDIA-Certified Systems.

1. Accelerated Computing Is a Full-Stack, Data-Center-Scale Problem

  • Full-stack: you have to optimize and integrate every layer (hardware, system software, libraries, frameworks) to get top performance.
  • Data-center scale: "The data center is the new unit of computing." Applications span the whole data center, so every component must be optimized.

The NVIDIA platform stack (bottom to top)

Layer Contents
Hardware GPUs, CPUs, DPUs, which are built into servers
Programming models CUDA for GPUs, DOCA for DPUs
Acceleration libraries E.g. CUDA-X, which gives developers acceleration transparently across hardware
Application frameworks Built for specific domains: Riva (conversational AI), DRIVE (autonomous vehicles), Merlin (recommenders) and more

2. The Three Pillars: CPU + GPU + DPU

Pillar Job
GPU Accelerated computing: parallel processing at huge scale for graphics and AI
CPU General application processing, especially single-threaded work it does well
DPU Data-intensive infrastructure work: communications processing, compression, encryption. It keeps the data center efficient
  • Together, GPU + CPU + DPU make up the new unit of computing.
  • Just as every smartphone has graphics and AI processors, every server and workstation will have accelerators. Many will also have DPUs to speed up the network, storage and security services at the heart of cloud-native computing.

3. Ways to Get AI Compute

Option What it offers
Cloud service providers (CSPs) Infrastructure without managing or maintaining it. High-density compute and virtual workstations anytime, anywhere, with no physical data center. Covered in a later unit
OEM systems Systems from established, certified vendors built from standard components, giving flexibility
NVIDIA DGX Purpose-built with optimized compute, networking and storage, plus access to NVIDIA's expertise for deployment and maintenance

4. From Idea to Production

  • An AI application goes from ideation to a trained model in production through several phases.
  • The team includes data scientists, data engineers, business analysts, DevOps and application developers.

5. Where Accelerated Computing Runs

  • Cloud: virtual desktops, apps, workstations and optimized containers, so data scientists can run GPU-accelerated AI from their desks.
  • Data center: breakthrough performance at any scale with fewer servers, giving faster insights and much lower cost. Sensitive data stays secure.
  • Edge: needs a scalable, accelerated platform for real-time decisions at the point of action: stores, factories, hospitals, smart cities. NVIDIA Jetson is the edge platform.

Key Terms

  • Full-stack acceleration: optimizing hardware, software and frameworks together.
  • Data center as the unit of computing: applications span the whole data center.
  • CUDA / DOCA: programming models for GPUs / DPUs.
  • CUDA-X: NVIDIA's GPU acceleration libraries.
  • Riva / DRIVE / Merlin: domain frameworks for conversational AI / autonomous vehicles / recommenders.
  • Jetson: NVIDIA's platform for edge AI.

Exam Tips

  • The three pillars are CPU (general, single-thread), GPU (parallel acceleration) and DPU (infrastructure: networking, security, storage).
  • CUDA is for GPUs. DOCA is for DPUs.
  • The data center is the new unit of computing, which is why acceleration is full-stack.
  • The three ways to consume AI compute are cloud, OEM and DGX.
  • Jetson is for the edge.

Lesson 2 of 4GPUs and CPUs for AI

1. Quick Recap

  • CPUs run complex instruction sets on a few, increasingly multi-core processors. GPUs run simple instruction sets across many cores at the same time. They work together.
  • GPU architecture covers the compute units, memory, caches, rendering pipelines and interconnects.

2. NVIDIA Architectures at a Glance

Architecture Type Built for Named after
Blackwell GPU (latest) Large-scale generative AI: training and inference for the largest LLMs David Blackwell, a mathematician and statistician (probability, game theory, information theory). He independently developed dynamic programming and the Rao–Blackwell theorem
Hopper GPU (prior flagship) Large-scale AI, HPC and data analytics, e.g. conversational AI Grace Hopper, one of the first programmers of the Harvard Mark I. She invented one of the first linkers
Ada Lovelace GPU Gaming, AI-powered graphics, ray tracing, plus data center workloads (L40S) Ada Lovelace, whose notes on Babbage's Analytical Engine are considered the first computer program
Grace CPU (Arm) HPC and data centers. Combines Arm CPU architecture with NVIDIA AI and parallel-computing expertise Grace Hopper
  • Multi-Instance GPU (MIG) on Blackwell and Hopper splits one GPU into up to 7 fully isolated instances, each with its own high-bandwidth memory, cache and compute cores.

3. GPU Products

B200 (Blackwell)

  • 208 billion transistors plus HBM. Described as the world's largest, most powerful accelerator.
  • Second-generation Transformer Engine: custom Blackwell Tensor Cores + TensorRT-LLM + NeMo. It speeds up training and inference for LLMs and mixture-of-experts (MoE) models.
  • Confidential Computing protects data and models without a performance penalty.
  • Fifth-generation NVLink scales up to 576 GPUs, for trillion and multi-trillion-parameter models.
  • Decompression engine plus access to Grace CPU memory speeds up whole database query pipelines for data analytics.
  • RAS engine (reliability, availability, serviceability) spots faults early to minimize downtime.

H100 (Hopper)

  • 80 billion transistors and a Transformer Engine for LLMs.
  • Confidential Computing: processes sensitive data in an encrypted, isolated environment, which matters especially in the cloud.
  • 900 GB/s GPU-to-GPU interconnect.
  • MIG lets multiple users or apps share one GPU securely.
  • Example use: training neural networks for self-driving cars.

L40S (Ada Lovelace)

  • For generative AI and LLM inference and training, 3D graphics, rendering and video.
  • Fourth-generation Tensor Cores, the specialized units that speed up DL training and inference.
  • Advanced video acceleration. Ada GPUs deliver up to 2× the power efficiency of the previous generation.

4. Grace CPU and the Superchips

  • NVIDIA Grace is NVIDIA's first data center CPU. It's Arm-based and built for HPC, and also suits cloud and hyperscale because it's energy-efficient and scalable.
  • It's ideal for memory- and bandwidth-hungry workloads: genomics, computational fluid dynamics, quantum chemistry.
Superchip Combination Best for
Grace Hopper (GH200) Grace CPU + H100 GPU over NVLink-C2C (chip-to-chip) The most versatile platform for scale-out. Coherent CPU↔GPU memory, a large unified memory model. It shines when CPU performance and memory bandwidth matter: recommenders, graph databases, scientific computing
Grace Blackwell (GB200) Grace CPU + two B200 GPUs over NVLink-C2C at 900 GB/s bidirectional Coherent unified memory that simplifies programming for trillion-parameter LLMs, multimodal transformers, large simulations and 3D generative models
Grace CPU Superchip Two Grace CPUs (CPU-only) CPU apps where performance, energy efficiency and density matter: scientific computing, cloud, analytics, enterprise, hyperscale. It packs the performance of a flagship two-socket x86-64 server into one superchip

Key Terms

  • MIG (Multi-Instance GPU): splits one GPU into up to 7 isolated instances.
  • Transformer Engine: hardware and software in Hopper and Blackwell that speed up transformer models.
  • Tensor Cores: specialized units for deep learning math.
  • Confidential Computing: processing data in an encrypted, isolated environment on the GPU.
  • NVLink-C2C: a coherent chip-to-chip link between Grace and the GPU.
  • Superchip: CPU and GPU (or CPU and CPU) packaged together with NVLink-C2C.
  • MoE (mixture of experts): a model architecture the Blackwell Transformer Engine speeds up.

Exam Tips

  • Architecture to product: Blackwell → B200, Hopper → H100, Ada Lovelace → L40S, Grace → the Arm CPU.
  • Know the numbers: B200 has 208B transistors, 5th-gen NVLink, scales to 576 GPUs. H100 has 80B transistors and 900 GB/s GPU-to-GPU. MIG gives up to 7 instances.
  • Both H100 and B200 have Confidential Computing.
  • GH200 = Grace + H100. GB200 = Grace + 2× B200. Both use NVLink-C2C for coherent unified memory.
  • Grace targets HPC, memory-bound workloads and energy-efficient hyperscale.
  • L40S fits mixed workloads: generative AI plus graphics, rendering and video.

Lesson 3 of 4Multi-GPU Systems

1. Scale Up vs. Scale Out

Scale up = multi-GPU Scale out = multi-node
What you add More GPUs in one node More nodes in the system
Hardware One node with many GPUs + a high-speed GPU interconnect Many nodes, each with its own processing, connected by a network
Data distribution Across GPUs Across nodes
Load balancing Between GPUs Between nodes
Fault tolerance Lower: one failed GPU can affect the whole system Higher: one failed node doesn't take down the system

2. How GPUs Talk Inside a Server

Technology What it does Limitation
PCIe The traditional server interconnect Becomes a bottleneck as workloads grow and GPUs get faster
NVLink Connects GPUs much faster than PCIe so they can share memory at high speed In all-to-all communication, some GPU pairs still fall back to slower PCIe
NVSwitch Any GPU can talk directly to any other GPU with no bottleneck. Every GPU connects over NVLink to all the NVSwitch fabrics It's the answer for scaling beyond 8 GPUs and for all-to-all traffic
  • All-to-all operations happen when every GPU needs to talk to every other GPU at once, e.g. distributing data. They're common in AI and HPC.

4. The Wider DGX and Blackwell Portfolio

  • DGX systems are multi-GPU AI supercomputers: top GPUs, ultra-fast interconnects and an integrated software stack. The family runs from H100 and H200 to Blackwell, across cloud and on-prem.
  • GB300 NVL72:
    • a fully liquid-cooled, rack-scale system
    • 36 Arm-based Grace CPUs + 72 Blackwell Ultra GPUs, linked by fifth-generation NVLink into one platform
    • purpose-built for test-time scaling inference and AI reasoning
    • also runs diffusion-based real-time video generation from world foundation models such as NVIDIA Cosmos, for physical AI
  • RTX PRO 6000 Blackwell Server Edition:
    • 96 GB of GDDR7
    • handles agentic AI, physical AI, scientific computing, rendering, 3D graphics and video
    • RTX PRO servers built on it bring Blackwell performance and efficiency to AI factories and every enterprise workload

Key Terms

  • Scale up / scale out: more GPUs per node / more nodes.
  • NVLink: NVIDIA's high-speed GPU-to-GPU link, much faster than PCIe.
  • NVSwitch: a switch fabric giving full-bandwidth any-to-any GPU communication.
  • All-to-all: every GPU exchanging data with every other GPU at the same time.
  • ConnectX-7: the 400 Gb/s network adapter in DGX H100.
  • DGX OS: NVIDIA's optimized, supported Ubuntu for DGX.
  • NVL72: a rack-scale system with 72 GPUs linked by NVLink.

Exam Tips

  • Scale up means multi-GPU. Scale out means multi-node. Multi-node has better fault tolerance.
  • PCIe bottlenecks. NVLink is faster. NVSwitch removes all-to-all bottlenecks and scales past 8 GPUs.
  • Memorize the DGX H100 specs: 8× H100, 4 NVSwitches, 10× ConnectX-7 at 400 Gb/s, 2× Xeon (112 cores), 2 TB RAM, 30 TB NVMe, 32 PFLOPS, 8U, DGX OS (Ubuntu).
  • GB300 NVL72 = 36 Grace + 72 Blackwell Ultra, liquid-cooled, built for reasoning and test-time scaling.

Lesson 4 of 4Introduction to DPUs

1. What a DPU Is

  • The third pillar of the data center, alongside the CPU and GPU.
  • A data center infrastructure on a chip. It enables software-defined, hardware-accelerated IT infrastructure.
  • Why it's needed: running infrastructure services on the host CPU steals CPU cores and hurts application performance, sometimes severely.

The DPU mission: offload, accelerate, isolate

Verb Meaning
Offload Takes infrastructure tasks off the server CPU, freeing it for applications (the "money-making" work)
Accelerate Runs those functions faster than the CPU using dedicated hardware accelerators, which speeds up network traffic and apps
Isolate Moves critical data plane and control plane functions into a separate domain on the DPU, protecting them even if the host CPU or its software is compromised
  • A DPU has specialized accelerators for networking, security and storage. They're more efficient and use less power than CPU cores.
  • It also suits compute-heavy jobs where space is tight, such as the far edge.

2. NVIDIA BlueField-3

  • The third-generation NVIDIA DPU and infrastructure compute platform, from cloud to core to edge.
  • Connectivity: 400 Gb/s Ethernet or NDR 400 Gb/s InfiniBand.
  • It offloads, accelerates and isolates software-defined networking, storage, security and management.

BlueField use cases

Area How BlueField helps
Cloud / CSPs The largest CSPs use it for efficiency and scale. Runs in bare-metal and virtualized clouds, and Kubernetes clusters (often on bare metal). Secures bare-metal clouds
Cybersecurity Next-generation firewalls (NGFW), micro-segmentation. Enables zero trust everywhere, pushing security to the edge of every server, not just the perimeter
Storage NVMe over Fabrics (NVMe-oF), GPUDirect Storage, data integrity, decompression, deduplication. Remote storage performance rivals direct-attached storage
HPC/AI, telco, enterprise storage, CDN Faster performance and new functions
Video streaming Offloads streaming from the CPU, saving CPU cycles

3. NVIDIA DOCA

  • The open cloud SDK and acceleration framework for BlueField DPUs. It does for DPUs what CUDA does for GPUs.
  • It uses industry-standard APIs to quickly build networking, storage and infrastructure services on BlueField. It supports BlueField-3.

4. NVIDIA-Certified Systems

  • What they are: NVIDIA GPUs + NVIDIA networking in servers from leading vendors. They follow NVIDIA design best practices and pass certification tests for performance, manageability, scalability and security.
  • Why: enterprises can confidently pick optimized hardware with enterprise-grade support, from small setups to at-scale deployments.
  • Security at every layer: platform, network and application. Applies in the data center, at the edge, and on laptops and desktops.

Validated capabilities

Capability Benefit
GPU acceleration Record-setting ML, DL and analytics, plus fast video processing and rendering
High-speed interconnects Move data directly to GPUs quickly
Encryption offload for TLS and IPsec Secures data in motion without losing throughput
Key management + secure boot Host-level security
Accelerated GPU↔server data transfer Efficient multi-node processing for the biggest jobs, such as large model training
Multi-Instance GPU (MIG) Splits one GPU into independent instances for flexible use within a host

Key Terms

  • DPU: data processing unit, an infrastructure-on-a-chip that offloads, accelerates and isolates.
  • Data plane / control plane: packet handling / management logic. Both can run isolated on the DPU.
  • BlueField-3: NVIDIA's third-generation DPU, with 400 Gb/s Ethernet or NDR InfiniBand.
  • DOCA: the SDK for programming BlueField DPUs.
  • NVMe-oF: NVMe over Fabrics, network access to NVMe storage.
  • GPUDirect Storage: a direct path between storage and GPU memory.
  • Zero trust: security enforced at every server, not just the perimeter.
  • NVIDIA-Certified System: a partner server validated with NVIDIA GPUs and networking.

Exam Tips

  • The DPU mission is offload, accelerate, isolate. Know what each word means.
  • DPUs free CPU cores for applications and protect infrastructure if the host is compromised.
  • DOCA is for DPUs as CUDA is for GPUs.
  • BlueField-3 runs at 400 Gb/s (Ethernet or NDR InfiniBand). Use cases: CSP and bare-metal clouds, zero trust / NGFW / micro-segmentation, NVMe-oF and GPUDirect Storage, video streaming.
  • Certified systems = NVIDIA GPUs and networking on partner servers, tested for performance, manageability, scalability and security.
  • Certified security features: TLS and IPsec offload, secure boot, key management.
